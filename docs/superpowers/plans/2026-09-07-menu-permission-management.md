# 菜单与权限管理实施计划

1. 通过 V5 增加菜单内置标识、菜单管理入口和操作权限，并更新迁移测试。
2. 扩展菜单实体、命令、视图、错误码及 Mapper XML，补充跨租户关联定位查询。
3. 实现菜单领域服务的字段、层级、循环、内置和删除约束，并在权限变化后刷新认证版本、撤销会话。
4. 提供管理树、详情、创建、更新、启停和删除 Controller，逐方法绑定精确权限码。
5. 建设前端菜单管理路由、侧栏入口、树表和动态表单，支持明暗主题下的现有后台样式。
6. 执行后端全量测试、前端 ESLint、类型检查、生产构建和 Git 差异检查；本地无 Docker，不执行 Compose 验证。
